# Example test audio

Generated by [`../generate-test-audio.js`](../generate-test-audio.js) —
Piper-synthesized VHF phrases, used to test the speech-to-text feature
(`POST /transmissions/:id/transcribe`) end to end without a real radio.
See README.md's "Known limitation: standard VHF prowords transcribe
poorly on the default model" for what these surfaced.

Each phrase has two files:

- **`*-piper-raw.wav`** — Piper's original output (22.05kHz, the voice's
  native rate).
- **`*-whisper-input.wav`** — the same speech after simulating the real
  M510E's audio path: resampled to 8kHz, mu-law encoded, framed as fake
  RTP packets matching the real radio's wire format, then run through the
  exact frame → write → unframe → extract → decode round-trip
  `lib/rtpAudio.js` uses for a real recording. This is what actually gets
  sent to the Wyoming ASR service — not the piper-raw file.

Regenerate (needs a Piper Wyoming service, e.g. via signalk-piper,
reachable at `127.0.0.1:10200` by default):

```sh
node scripts/generate-test-audio.js
```
